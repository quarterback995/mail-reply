# Mail-Reply-Agent Frontend

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. The app will be available at `http://localhost:5173`

## Features

- **Drafting Workspace**: Split-screen interface for pasting incoming emails and generating AI-powered replies
- **Data Library**: Upload and manage style samples and knowledge base documents
- **Dark Mode**: Modern, engineering-oriented aesthetic with dark theme
- **Responsive Design**: Works on desktop and mobile devices

## Tech Stack

- React + Vite
- Tailwind CSS
- Axios for API communication
- React Router for navigation
